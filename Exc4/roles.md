| Роль            | Права роли                                                                                                                                                                                      | Описание                                                                  |
|-----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| privileged-role | Полный доступ ко всем ресурсам кластера, включая просмотр секретов (verbs: “*” для всех ресурсов)                                                                                               | Группа ИБ / DevOps администраторы                                         |
| readonly-role   | Доступ только для просмотра (verbs: get, list, watch; ресурсы: все)                                                                                                                             | Группа наблюдателей, аналитиков                                           |
| configurer-role | Возможность настраивать ресурсы кластера (например, pods, deployments, services, configmaps, secrets), с ограниченным набором действий (verbs: get, list, watch, create, update, patch, delete) | Группа разработчиков / DevOps специалистов, ответственных за конфигурацию |
